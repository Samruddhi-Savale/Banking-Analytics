# **🏦 Banking Analytics Project**

### End-to-End Banking Data Analytics & Business Intelligence

**Tools:** Excel • Python • MySQL • Power BI • MDD • CSV

---

## 📌 Project Overview

The **Banking Analytics Project** is an end-to-end data analytics project focused on analyzing customer demographics, deposits, loans, savings, income, fees, and risk.

The project follows a complete analytics workflow:

**Data Audit → Data Cleaning → EDA → ML → SQL Analysis → Power BI Dashboard → Business Insights**

---

## 🎯 Business Objectives

* Analyze customer demographics and financial behavior
* Understand deposits, loans, savings, and income patterns
* Identify high-risk customers and financial segments
* Analyze customer loyalty and occupation-wise performance
* Generate actionable business insights through an interactive dashboard

---
